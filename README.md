# Murgaxor Sounds

Локальная панель звуков для настольных игр с тематической музыкой и управлением Discord-ботом.

## Запуск

1. Запусти `start-server.bat`.
2. Открой `http://localhost:3040`.
3. Чтобы остановить сервер, запусти `stop-server.bat`.

При первом запуске создастся `.env` из `.env.example`. Обычная звуковая панель работает на встроенном Node.js без установки пакетов.

## Админ-панель

Нажми `Админ` вверху сайта. Пароль по умолчанию: `admin`; его можно поменять в `.env` через `ADMIN_PASSWORD`.

В админ-панели можно:

- загрузить аудио как звук или как музыку;
- для звука выбрать категорию эффектов и обложку;
- для музыки выбрать тему/настроение и обложку;
- загрузить свои картинки превью для звуков, музыки и тем;
- редактировать существующие звуки и музыку: название, тип, файл, категорию, тему и превью;
- удалять звуки или музыку из сайта;
- создавать новые музыкальные темы;
- редактировать темы: название, обложку и состав плейлиста;
- удалять созданные темы вместе с их плейлистами, не удаляя сами треки из медиатеки.

## Возможности сайта

- Верхние карточки тем переключают фон сайта и музыкальный плейлист.
- Музыка хранится в плейлистах тем и запускается из правой панели.
- YouTube URL можно вставить отдельно; он воспроизводится вместо текущей музыки через Discord.
- Звуки сгруппированы по категориям: природа, бой, город, подземелье, эмбиенс, существа и эффекты.
- У каждого звука есть своя громкость, избранное и индивидуальный автоповтор.
- У каждой категории звуков есть кнопка дефолтного автоповтора: новые звуки в этой категории будут запускаться с повтором или без него.
- Есть общая громкость и отдельная громкость музыки.
- Можно выбрать режим вывода: звук на этом ПК или звук только через Discord-бота.
- Настройки сохраняются локально в браузере.

## Discord-бот

1. Открой Discord Developer Portal и создай приложение.
2. В разделе Bot создай бота и скопируй Bot Token в `.env` как `DISCORD_TOKEN`. Не используй Public Key из General Information.
3. Скопируй Application ID в `.env` как `DISCORD_CLIENT_ID`.
4. Скопируй ID сервера в `DISCORD_GUILD_ID` и ID голосового канала в `DISCORD_VOICE_CHANNEL_ID`.
5. Запусти `install-discord-deps.bat`.
6. Выполни `npm run discord:invite`, открой ссылку и пригласи бота на сервер.
7. Перезапусти сервер через `stop-server.bat`, затем `start-server.bat`.

Браузерная панель умеет одновременно запускать локальные звуки у тебя на компьютере или отправлять текущий локальный микс в Discord. Музыкальные плейлисты формируются по темам из загруженной музыки. YouTube работает как отдельное поле URL и воспроизводится вместо текущей музыки через Discord.

Если YouTube снова просит подтвердить, что запрос не от бота, основной вариант для стабильной работы без Chrome в фоне:

1. Открой YouTube в обычном браузере, войди в аккаунт и открой любое видео.
2. Экспортируй cookies YouTube в Netscape `.txt` через расширение для экспорта cookies.
3. Сохрани файл как `tools/youtube-cookies.txt`.
4. Проверь, что в `.env` указан путь:
   `YTDLP_COOKIES_FILE=C:\Users\dggol\Documents\LeavePlz Sounds\tools\youtube-cookies.txt`
5. Перезапусти сервер через `stop-server.bat`, затем `start-server.bat`.

Если YouTube снова покажет сообщение про устаревшие cookies, повтори экспорт и замени `tools/youtube-cookies.txt` свежим файлом.

Запасные варианты:

1. Закрыть все окна Chrome и использовать `YTDLP_COOKIES_FROM_BROWSER=chrome`.
2. Обновить ручной `YOUTUBE_COOKIE`, если используешь старый способ через заголовок Cookie.

Если Chrome пишет `Could not copy Chrome cookie database`, значит браузер держит файл cookies открытым. Закрой Chrome полностью, включая фоновые процессы, или используй `YTDLP_COOKIES_FILE`.
